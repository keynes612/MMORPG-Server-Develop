====================================================================
               [팀원 공유용] 초보자를 위한 Git & GitHub 시작 가이드
====================================================================

이 가이드는 Git을 처음 접하는 사람도 순서대로 명령어만 복사/붙여넣기하면
원격 저장소 연결부터 Push(업로드)까지 마칠 수 있도록 정리한 요약본입니다.

--------------------------------------------------------------------
1. 환경 설정 및 초기화 (프로젝트당/컴퓨터당 처음 1회만 실행)
--------------------------------------------------------------------

[1] 사용자 정보 등록 (컴퓨터에서 Git을 처음 쓰는 경우)
    git config --global user.name "본인이름"
    git config --global user.email "깃허브이메일"

[2] 현재 폴더를 Git 저장소로 만들기
    작업 중인 프로젝트 폴더 경로에서 터미널(또나 Git Bash)을 열고 실행:
    git init

[3] 원격 저장소(GitHub)와 연결
    GitHub에서 생성한 저장소 주소(https://github.com/...git)를 붙여넣기:
    git remote add origin https://github.com/사용자계정/저장소이름.git

    * 연결 상태 확인: git remote -v


--------------------------------------------------------------------
2. 기본 작업 흐름: 파일 올리기 (Add -> Commit -> Push)
--------------------------------------------------------------------

코드나 파일을 변경한 후, 온라인 저장소에 올릴 때마다 아래 3단계를 순서대로 실행합니다.

[1단계] 올릴 파일 선택하기 (Stage)
    수정한 모든 파일을 올릴 준비 상태로 전환합니다.
    git add .

    * 파일 상태 확인하고 싶을 때: git status

[2단계] 저장하기 (Commit)
    선택한 파일들을 하나의 버전으로 기록하고 어떤 작업을 했는지 설명글을 남깁니다.
    git commit -m "작업 내용 요약 (예: 로그인 페이지 레이아웃 구현)"

[3단계] GitHub로 전송하기 (Push)
    내 컴퓨터에 기록된 버전을 온라인 GitHub 저장소로 올립니다.
    git push -u origin main

    * 참고: 저장소에 따라 'main' 대신 'master'로 되어 있을 수 있습니다.
    * -u 옵션으로 처음 등록한 이후부터는 simplemente 'git push'만 입력해도 됩니다.


--------------------------------------------------------------------
3. 최신 변경사항 가져오기 (Pull)
--------------------------------------------------------------------

다른 팀원이 올린 최신 코드나 변경사항을 내 컴퓨터로 받아올 때 사용합니다.
작업 시작 전에 항상 먼저 실행해주는 것이 좋습니다.

    git pull origin main


--------------------------------------------------------------------
[요약] 일상적으로 가장 많이 쓰는 3대 명령어
--------------------------------------------------------------------
1. git add .                : 변경된 모든 파일 선택
2. git commit -m "메시지"   : 변경사항을 설명과 함께 기록
3. git push                 : 온라인 GitHub로 업로드
